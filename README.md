alquileres) es parte de la app de Tecsul, junto con Obras:

- App: https://tecsul-obras.github.io/Cronograma-de-obras/equipos/parte_diario_v5.html
- Código: repo `tecsul-obras/Cronograma-de-obras`, carpeta `equipos/`
- Funciones del servidor: `supabase/functions/usuarios` y `supabase/functions/asistente-equipos` de ese repo
- Base de datos: el proyecto de Supabase del cronograma (sququxlqcrbsoqvmycfa)

Este repo queda solo para redirigir las direcciones viejas y desinstalar el
service worker viejo de los celulares. La historia completa del código está
en los commits anteriores.
